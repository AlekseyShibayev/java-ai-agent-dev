# Конституция

Каждый пункт помечен `[<буква><номер>]` и проверяется в `.githooks/pre-commit`: пункт без метки или метка без проверки блокируют коммит.

## Security

1. `[S0]` Любое изменение этого файла — только по согласованию с человеком: агент не правит пункты сам.
2. `[S1]` Агенту в базе данных выдаётся только роль с правами на чтение (`read_only`).
3. `[S2]` Секрет — приватный ключ, токен, пароль или иные учётные данные — в коммит не попадает: репозиторий публичен, а история необратима. В файлах только ссылка на переменную окружения или явно фиктивный образец.
4. `[S3]` Адрес подключения — схема, хост и порт — в файлах не хранится даже без пароля: он раскрывает топологию. Вместо адреса имя переменной, значение приходит при запуске.
5. `[S4]` Секрет остаётся в конфиге запуска и не покидает его: ни в логе, ни в ошибке, ни в ответе агента, ни в trace. Критерий — значение, известное приложению, не встречается нигде вне конфига.
6. `[S5]` Локальный конфиг с секретами не индексируется: `application*.yaml` в корне и `.env*` закрыты `.gitignore`, launcher-каталог лежит вне репозитория.

Проверки безопасности — эвристика по известным образцам; остаточный риск закрывают ревью, `.gitignore` и ротация, а не хук.
