## Инструкции для агента

Правила выполнения:

- Бери первый пункт с `[ ]` из чек-листа, если человек не указал другой.
- Выполняй шаги по порядку и обязательно прогоняй проверку.
- При успехе: поставь `[x]` в чек-листе, заполни `Результат` и дату.
- Если нужен человек (UI IDE, пароль, подтверждение) — остановись и напиши, что именно сделать.
- Секреты и токены в этот файл не записывай: репозиторий публичный.
- Новую задачу добавляй как `SETUP-N`: строка в чек-листе + раздел с таким же ID.

### SETUP-0. Создать `AGENTS.md`

**Статус:** done
**Цель:** дать агенту постоянные инструкции по репозиторию.

**Шаги:**
1. Создать `AGENTS.md` в корне репозитория.
2. Включить: команды сборки и тестов, стек и версии, текущее состояние проекта, конфигурацию и секреты, особенности окружения, правила git, процесс задач, стиль работы.
3. Убедиться, что команды из файла действительно работают.

**Проверка:**
```bash
test -f AGENTS.md && echo ok
```

**Готово, когда:** файл существует, команды проверены, секретов нет.

**Результат:** создан и поддерживается.

### SETUP-1. Установить глобальный навык `skill-creator`

**Статус:** done
**Цель:** навык создания и улучшения skills доступен во всех проектах.

**Шаги:**
1. Склонировать `anthropics/skills`.
2. Скопировать `skills/skill-creator` в `~/.config/opencode/skills/`.
3. Убедиться, что проектная копия лежит в `.opencode/skills/`.

**Команды:**
```bash
mkdir -p ~/.config/opencode/skills
git clone --depth 1 https://github.com/anthropics/skills /tmp/anthropic-skills
cp -r /tmp/anthropic-skills/skills/skill-creator ~/.config/opencode/skills/
rm -rf /tmp/anthropic-skills
```

**Проверка:**
```bash
test -f ~/.config/opencode/skills/skill-creator/SKILL.md && echo ok
```

**Готово, когда:** глобальная копия существует, навык виден в новой сессии.

**Результат:** установлен глобально и в проекте.

### SETUP-2. Настроить MCP с IntelliJ

**Статус:** done
**Цель:** агент использует инструменты IDE: сборка, инспекции, поиск, отладка.

**Шаги:**
1. В IDE: `Ctrl+Alt+S` → **AI → MCP Server** → **Enable MCP Server** → Apply.
2. В `opencode.json` добавить remote-сервер на HTTP Stream endpoint IDE.
3. Проверить подключение.

**Конфигурация:**
```json
{
  "mcp": {
    "servers": {
      "intellij": {
        "type": "remote",
        "url": "http://127.0.0.1:64342/stream"
      }
    }
  }
}
```

**Проверка:**
```bash
/home/user/.opencode/bin/opencode mcp list
```

Ожидаемо: `intellij connected`.

**Готово, когда:** `mcp list` показывает `connected`, инструменты доступны в сессии.

**Результат:** подключено, 40 инструментов.
**Грабли:** SSE (`/sse`) не поддерживается — `HTTP 405`; `mcp-remote` требует Node 20+, на Node 18 падает.

### SETUP-3. Открыть актуальный проект в IntelliJ

**Статус:** pending
**Цель:** MCP-инструменты работают с текущим путём репозитория, а не со старым после переименования.

**Шаги:**
1. В IDE: **File → Open** → каталог репозитория `java-ai-agent-dev`.
2. Дождаться индексации.
3. Проверить, что MCP видит этот проект.

**Проверка:** вызвать `tools.intellij.get_project_modules` с `projectPath`, равным пути репозитория.

**Готово, когда:** IDE открывает актуальный каталог, инструменты отвечают по нему.

**Результат:** ожидает выполнения человеком.
