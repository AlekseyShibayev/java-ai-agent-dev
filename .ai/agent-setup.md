# AI Agent Setup

Чек-лист задач для старта работы с AI-агентом.
Сверху — список для человека, ниже — таблица с критериями для агента.

## Задачи

- [x] 1. Создать `AGENTS.md`
- [x] 2. Установить глобальный навык `skill-creator`
- [x] 3. Настроить MCP с IntelliJ

## Критерии и ограничения

| № | Критерий готовности | Ограничения | Грабли |
| --- | --- | --- | --- |
| 1 | `AGENTS.md` существует, команды из него проверены и работают | Не добавлять секреты; не дублировать README | Команды должны быть проверены на этой машине, а не переписаны из шаблона |
| 2 | `~/.config/opencode/skills/skill-creator/SKILL.md` существует | Не менять содержимое навыка; не удалять проектную копию | Глобальная копия в `~/.config/opencode/skills`, проектная — в `.opencode/skills` |
| 3 | `opencode mcp list` показывает `intellij connected` | Не включать brave mode в IDE без разрешения; не хранить токены | SSE `/sse` даёт `405` — нужен `/stream`; `mcp-remote` падает на Node 18 |

## Правила для агента

1. Бери первый пункт с `[ ]` по порядку.
2. Проверь критерий готовности, только потом ставь `[x]`.
3. Если нужен человек (UI, пароль, подтверждение) — остановись и напиши, что именно сделать.
4. Секреты в файл не записывай: репозиторий публичный.
