# Роли из коробки

В OpenCode доступны четыре агента:

- **Сборка** (`build`, primary) — основная работа: код, правки, команды. Чтение чувствительных env-файлов требует подтверждения.
- **Планирование** (`plan`, primary) — исследование и планирование без правок обычных файлов; shell-команды по разрешению.
- **Общий** (`general`, subagent) — исследование и многошаговые задачи с широким доступом к инструментам; не запускает других субагентов.
- **Исследование** (`explore`, subagent) — поиск и чтение кода или веба без редактирования.
- **Custom** — свои роли, не из коробки: файл `.opencode/agents/<name>.md`, ID = имя файла.

Обращаться к роли нужно по системному ID — латиницей. Русское название можно указать в `name`, но оно только для отображения: файл с кириллическим именем роль не регистрирует. Встроенные роли переименовать нельзя.

Скрытые служебные агенты — `compaction`, `title`, `summary`: обслуживают сессию, напрямую не выбираются.
