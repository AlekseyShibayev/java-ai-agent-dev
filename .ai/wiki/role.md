# Роли из коробки

В OpenCode доступны четыре агента:

- **Build** (`build`, primary) — основная работа: код, правки, команды. Чтение чувствительных env-файлов требует подтверждения.
- **Plan** (`plan`, primary) — исследование и планирование без правок обычных файлов; shell-команды по разрешению.
- **General** (`general`, subagent) — исследование и многошаговые задачи с широким доступом к инструментам; не запускает других субагентов.
- **Explore** (`explore`, subagent) — поиск и чтение кода или веба без редактирования.
- **Custom** — свои роли: файл в `.opencode/agents/` или `~/.config/opencode/agents/`, либо `agents.<id>` в `opencode.json`.

Обращаться к роли нужно по системному ID. У встроенных ролей он английский: `build`, `plan`, `general`, `explore`. У своих ролей ID — это путь к файлу без `.md`, поэтому файл можно назвать и по-русски: `архитектор.md` → `архитектор`. Для CLI и логов латиница удобнее, но кириллица работает. Встроенные роли переименовать нельзя.

Скрытые служебные агенты — `compaction`, `title`, `summary`: обслуживают сессию, напрямую не выбираются.

## Где хранить

- **Проектные** — `.opencode/agents/<path>.md`: версионируются вместе с репозиторием и доступны внутри проекта. ID — путь без `.md`: `.opencode/agents/team/reviewer.md` → `team/reviewer`.
- **Глобальные** — `~/.config/opencode/agents/<path>.md`: доступны во всех проектах, в git не попадают.
- **В конфиге** — `opencode.json(c)`, объект `agents`: роль задаётся ключом (`agents.reviewer`) и не требует отдельного файла.

Каталог `agent/` (единственное число) тоже подхватывается, но документированный вариант — `agents/`.
