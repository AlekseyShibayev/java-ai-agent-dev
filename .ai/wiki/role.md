# Роли из коробки

В OpenCode доступны четыре агента:

- **Build** (`build`, primary) — основная работа: код, правки, команды. Чтение чувствительных env-файлов требует подтверждения.
- **Plan** (`plan`, primary) — исследование и планирование без правок обычных файлов; shell-команды по разрешению.
- **General** (`general`, subagent) — исследование и многошаговые задачи с широким доступом к инструментам; не запускает других субагентов.
- **Explore** (`explore`, subagent) — поиск и чтение кода или веба без редактирования.
- **Custom** — свои роли: проектный или глобальный файл, ID = имя файла.

Обращаться к роли нужно по системному ID. У встроенных ролей он английский: `build`, `plan`, `general`, `explore`. У своих ролей ID совпадает с именем файла, поэтому файл можно назвать и по-русски: `архитектор.md` → `архитектор`. Для CLI и логов латиница удобнее, но кириллица работает. Встроенные роли переименовать нельзя.

Скрытые служебные агенты — `compaction`, `title`, `summary`: обслуживают сессию, напрямую не выбираются.

## Где хранить

- **Проектные** — `.opencode/agents/<name>.md`: версионируются вместе с репозиторием и доступны только в этом проекте. Вложенная папка входит в ID: `.opencode/agents/team/reviewer.md` → `team/reviewer`.
- **Глобальные** — `~/.config/opencode/agents/<name>.md`: доступны во всех проектах, в git не попадают.
