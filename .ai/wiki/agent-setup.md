# AI Agent Setup

Универсальный чек-лист для старта работы с AI-агентом в любом проекте.
Не привязан к конкретному репозиторию: файл можно копировать в `.ai/wiki` другого проекта.

## Задачи

- [x] **1.** Создать `AGENTS.md`
- [x] **2.** Установить глобальный навык `skill-creator`
- [x] **3.** Настроить MCP с IDE

## Критерии и ограничения

| № | Критерий готовности | Ограничения | Грабли |
|:--:| --- | --- | --- |
| 1 | `AGENTS.md` существует в корне проекта, команды из него проверены и работают | Не добавлять секреты; не дублировать README | Команды зависят от ОС и окружения: проверять на машине, а не копировать из шаблона |
| 2 | `~/.config/opencode/skills/skill-creator/SKILL.md` существует | Не менять содержимое навыка без задачи; проектная копия опциональна | Скрипты навыка рассчитаны на Python и Claude CLI; в другом агенте часть evals потребует адаптации |
| 3 | MCP-сервер подключён и инструменты IDE доступны агенту | Не включать авто-исполнение команд в IDE без разрешения; не хранить токены | MCP-клиент может не поддерживать SSE — нужен HTTP Stream endpoint; stdio-прокси может требовать Node 20+ |

## Правила для агента

1. Бери первый пункт с `[ ]` по порядку.
2. Проверь критерий готовности, только потом ставь `[x]`.
3. Если нужен человек (UI, пароль, подтверждение) — остановись и напиши, что именно сделать.
4. Секреты в файл не записывай: репозиторий может быть публичным.
