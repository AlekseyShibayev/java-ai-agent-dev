# Telegram AI Dev Agent

## Цель проекта

Освоить основные нюансы работы агентской разработки.

## Основная концепция

Пользователь общается с агентом через Telegram-бота запущенного приложения.

Агент вносит изменения в приложение и может перезапустить его.

## Папка `.ai`

Здесь будет собираться информация, связанная с обучением работе с агентами.

## Стек

- **Java** — 21
- **Spring Boot** — 4.1.1
- **Gradle** — сборка проекта (wrapper в репозитории)
- **Персистентность** — PostgreSQL, `jsonb`, Spring Data
- **Telegram** — интерфейс взаимодействия с агентом
- **GitHub** — работа с репозиторием и изменениями
