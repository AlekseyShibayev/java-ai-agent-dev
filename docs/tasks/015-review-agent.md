## Goal

Человек не участвует в приёмке каждой задачи: `выполнено` проверяет отдельный агент-ревьюер, он же ставит `закрыто` или возвращает задачу в `в работе`, записав находки в файл задачи.

## Non-goals

Автоматический ревью-бот, CI-гейт, второй агент в одном worktree, изменение кода приложения.

## Acceptance criteria

- [ ] В `docs/task-statuses.md` `закрыто` ставит агент-ревьюер, а не человек; добавлен раздел «Ревью» с чек-листом и форматом вердикта.
- [ ] Возврат на доработку: `выполнено` → `в работе`, находки — блоком `## Ревью` в файле задачи (файл, строка, что не так).
- [ ] `AGENTS.md` ссылается на правило ревью и не противоречит ему.
- [ ] `docs/tasks/BOARD.md` не противоречит: те же четыре статуса.
- [ ] `./gradlew test` зелёный без фильтра.

## Tests

Код-тестов нет: задача про процесс.
