# Доска задач

Только взятые задачи: `в работе` и `на ревью`. `создано` живёт в файле `docs/tasks/NNN-slug.md` без строки в доске, `закрыто` — в `openspec/changes/archive/`. В файлах задач поля `status` нет.

| № | Задача | Статус | Кто |

| 018 | Оформление страницы чата | на ревью | junior |

`Кто` — короткий идентификатор взявшего: имя агента из `.opencode/agents/` или логин человека.

## Ревью

Находки ревьюера по задачам в статусе `на ревью`: `путь/файл:строка` — что не так и что ожидалось. Как только находки устранены, исполнитель удаляет блок задачи из этой секции отдельным коммитом в `main`; история остаётся в git, на доске — только открытые находки.

Правило жизненного цикла — `docs/task-statuses.md`.
