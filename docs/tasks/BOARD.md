Единственный источник статуса задачи. В файлах `docs/tasks/NNN-slug.md` поля `status` нет.

| № | Задача | Статус |
| --- | --- | --- |
| 003 | Рантайм чата: API | в работе |
| 004 | Страница чата и стриминг | создано |
| 009 | E2E страницы чата | создано |
| 010 | Статусы задач и процесс Джуна | создано |
| 011 | OpenSpec: практики, цель проекта, обучение | закрыто |
| 012 | OpenAPI: springdoc и Swagger UI | закрыто |
| 013 | Доска статусов задач | выполнено |

## Статусы

`создано` → `в работе` → `выполнено` → `закрыто`.

- **создано** — человек написал файл задачи. Агент берёт её только по прямому указанию.
- **в работе** — агент отметил в таблице, закоммитил это в `main` (в коммите только `BOARD.md` и файл задачи) и создал ветку `task/NNN-slug`.
- **выполнено** — ветка влита в `main`; ждём проверку человеком.
- **закрыто** — человек проверил; файл задачи удаляется, строка в таблице остаётся.

## Правила

- Строка добавляется при создании задачи и не удаляется; номер задачи неизменен.
- Номера неизменны: не переиспользуются и не меняются, даже после закрытия.
- Ветка задачу не меняет статус, кроме «выполнено» после merge; `BOARD.md` в ветке не правится, чтобы merge не конфликтовал.
- Два агента одновременно: claim = коммит в `main` + `git push`; `push` отклоняется, если `main` ушёл вперёд — тогда `git pull --rebase` и повторная проверка строки.
- Задачи из `docs/tasks/backlog/` на доску не попадают: они не начаты.
