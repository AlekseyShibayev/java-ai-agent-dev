# Архив задач

Файлы закрытых задач в том виде, в каком они были на момент `закрыто`. Правится только при переносе новой задачи: `git mv docs/tasks/NNN-slug.md docs/tasks/archive/`.

Статусы и история — `docs/tasks/BOARD.md`; правила — `docs/task-statuses.md`. Содержимое архивных файлов не актуализируется: это снимок, а не действующая задача.
