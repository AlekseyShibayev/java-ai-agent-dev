# Задачи

Одна задача — один файл `NNN-slug.md`. В `docs/tasks/` только незавершённые задачи; после `done` файл удаляется.

## Статусы

`draft` → `ready` → `in-progress` → `review` → `done` (или `blocked`).

## Процесс

1. Человек пишет файл, ставит `draft`, затем `ready`.
2. Агент: `in-progress`, ветка `task/NNN-slug`.
3. Реализация + тесты.
4. Проверка: acceptance закрыт, `./gradlew test` зелёный, человек проверил.
5. `done` → файл задачи удалить. История остаётся в коммитах и PR.

Держим только ближайшие задачи; завершённые удаляем.
