# Backlog

Задачи, которые не делаются сейчас. Файл переезжает сюда как есть: имя, номер, frontmatter и содержимое не меняются.

- Номер задачи — постоянный идентификатор. Номера не меняются и не переиспользуются: ни при переносе в backlog, ни при возврате.
- Возврат: файл переносится обратно в `docs/mini-jira/` с тем же номером; `BOARD.md` при переносе не правится, статус появляется, когда задачу взяли в работу.
- Новая задача получает следующий свободный номер после максимума по `docs/mini-jira/` **и** `docs/mini-jira/backlog/`.
- Задачи в backlog агент не берёт в работу.
