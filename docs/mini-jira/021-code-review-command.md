## Задача

Добавить команду code review, в которой можно будет сказать «code review» и номер ветки. Ветка при этом должна быть в статусе «на ревью»: когда её взяли на ревью, агент идёт в ту ветку и делает там ревью. Статус задачи при этом меняется — «на ревью» или что-то покрасивее, подумать над названием.
