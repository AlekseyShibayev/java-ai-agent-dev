## Goal

`/chat` сегодня — голый HTML без единого стиля: в `src/main/resources/static/` только `js/`, оформление не входило в AC 004. Сделать лёгкое, приятное оформление страницы чата одним локальным CSS-файлом: пузыри сообщений, закреплённый композер, индикатор генерации, тёмная тема по системной настройке. Без фреймворков и сети.

## Non-goals

Маркдаун и подсветка кода, карточки инструментов, reasoning/usage-панели, permissions (005/006), несколько сессий, кастомные шрифты и иконочные наборы, переписывание `chat.js` и логики 004.

## Depends on

004 (страница и стриминг) — поведение не меняется, меняется только внешний вид.

## Acceptance criteria

- [ ] `/chat` подключает локальный `/css/chat.css`; ссылок на CDN и внешних шрифтов нет — страница оформлена офлайн.
- [ ] `GET /css/chat.css` отдаётся сервером: 200, `Content-Type: text/css`.
- [ ] Сообщение пользователя и ответ ассистента визуально различаются: пузыри с разным выравниванием и фоном.
- [ ] Ответ читаем во время стриминга: переносы сохраняются, ширина ограничена, пока прогон активен виден индикатор генерации; после завершения он исчезает.
- [ ] Баннеры «Нет связи» и «OpenCode недоступен» видны над лентой и не перекрывают ввод.
- [ ] Композер закреплён внизу и не уезжает под ленту; `Отправить`/`Stop` в одном стиле, `:focus-visible` заметен, `disabled` отличим от активной кнопки.
- [ ] Тёмная тема включается по `prefers-color-scheme: dark`; по умолчанию — светлая.
- [ ] На ширине 375px нет горизонтальной прокрутки, кнопки не наезжают на поле ввода.
- [ ] Пустая подсказка «Начните диалог» скрывается, как только в ленте есть сообщение.
- [ ] Без CSS-фреймворков: один `static/css/chat.css` + `<link>`; прод-код ≤ 300 строк; `./gradlew test` зелёный без фильтра.

## Constraints

- `build.gradle`, существующие тесты, `chat.js`, контроллеры и шаблоны фрагментов не меняются; в `chat.html` добавляются только `<link>` и шапка.
- Без CDN, веб-шрифтов и иконочных наборов: системные шрифты и эмодзи.
- Новый тест — отдельный файл `ChatStylesTest`; правка существующих тестов запрещена.
- PR ≤ 300 строк.

## Out of scope

Кастомные шрифты, анимация появления сообщений, drag-and-drop, мобильное приложение, смена поведения стриминга и сессий.
