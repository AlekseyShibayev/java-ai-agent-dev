## Что сделать

Оформить `/chat` одним локальным CSS-файлом: пузыри сообщений, закреплённый композер, индикатор генерации, тёмная тема по системной настройке. Без фреймворков и сети.

Поведение и план — `openspec/changes/018-chat-styling/`.

## Приёмка

- [ ] `/chat` подключает локальный `/css/chat.css`; ссылок на CDN и внешних шрифтов нет — страница оформлена офлайн.
- [ ] `GET /css/chat.css` отдаётся сервером: 200, `Content-Type: text/css`.
- [ ] Сообщение пользователя и ответ ассистента визуально различаются: пузыри с разным выравниванием и фоном.
- [ ] Ответ читаем во время стриминга: переносы сохраняются, ширина ограничена, пока прогон активен виден индикатор генерации; после завершения он исчезает.
- [ ] Баннеры «Нет связи» и «OpenCode недоступен» видны над лентой и не перекрывают ввод.
- [ ] Композер закреплён внизу и не уезжает под ленту; `Отправить`/`Stop` в одном стиле, `:focus-visible` заметен, `disabled` отличим от активной кнопки.
- [ ] Тёмная тема включается по `prefers-color-scheme: dark`; по умолчанию — светлая.
- [ ] На ширине 375px нет горизонтальной прокрутки, кнопки не наезжают на поле ввода.
- [ ] Пустая подсказка «Начните диалог» скрывается, как только в ленте есть сообщение.
- [ ] Без CSS-фреймворков: один `static/css/chat.css` + `<link>`; прод-код ≤ 300 строк; `./gradlew test` зелёный без фильтра.
