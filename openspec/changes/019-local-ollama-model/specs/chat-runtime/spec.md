# Spec Delta

## Purpose

Рантайм прогона чата: по умолчанию прогон обслуживает локальная модель Ollama, а ошибка исполнения закрывает прогон ошибкой, а не оставляет его активным.

## ADDED Requirements

### Requirement: Локальная модель прогона по умолчанию

Система SHALL создавать сессию OpenCode с локальной моделью Ollama по умолчанию: провайдер `ollama`, модель `qwen3.5:4b-q4_K_M`.

#### Scenario: Прогон без переопределения

- **WHEN** сессия создаётся без переопределения провайдера и модели
- **THEN** OpenCode получает `{providerID: "ollama", id: "qwen3.5:4b-q4_K_M"}` и прогон обслуживает локальный Ollama

#### Scenario: Переопределение модели

- **WHEN** заданы `OPENCODE_PROVIDER` и `OPENCODE_MODEL`
- **THEN** сессия создаётся с переопределёнными провайдером и моделью, а дефолт не используется

### Requirement: Ошибка исполнения закрывает прогон

Система SHALL закрывать прогон статусом `failed`, когда OpenCode сообщает о терминальной ошибке исполнения `session.execution.failed`, и SHALL передавать клиенту сообщение провайдера.

#### Scenario: Провайдер недоступен во время прогона

- **WHEN** во время активного прогона приходит `session.execution.failed` с ошибкой провайдера
- **THEN** прогон закрывается `failed` с этой ошибкой, поток событий отправляет `state: failed` с текстом ошибки и завершается

#### Scenario: Промежуточная ошибка шага

- **WHEN** во время прогона приходит `session.step.failed`, а затем исполнение продолжается
- **THEN** прогон остаётся активным, потому что OpenCode повторяет шаг
