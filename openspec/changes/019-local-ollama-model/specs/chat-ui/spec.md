# Spec Delta

## Purpose

Страница чата: ошибка прогона видна в ленте, а поле ввода снова доступно — после запуска Ollama следующее сообщение проходит без перезагрузки.

## ADDED Requirements

### Requirement: Ошибка прогона на странице

Система SHALL показывать в блоке ответа текст ошибки прогона и SHALL разблокировать ввод, когда прогон закрылся ошибкой.

#### Scenario: Ollama остановлена

- **WHEN** прогон завершился состоянием `failed`
- **THEN** в блоке ответа виден текст ошибки, кнопка «Отправить» снова доступна, а поле ввода не заблокировано

#### Scenario: Повторный прогон после ошибки

- **WHEN** пользователь отправляет новое сообщение после неуспешного прогона и Ollama снова работает
- **THEN** сообщение отправляется в ту же сессию OpenCode и обслуживается локальной моделью
