# Proposal

## Why

Страница `/chat` показывает только текст ассистента: сервер уже публикует события инструментов, reasoning и usage, но `chat.js` их игнорирует. Пользователь не видит, какие инструменты вызывались, что они вернули, сколько это стоило и почему прогон остановился. Без этого чат не годится для обучения агентной разработке: шаги прогона — главный источник понимания.

## What Changes

- Карточка инструмента: имя и вход из события вызова, результат из части `tool` сообщения ассистента; карточка свёрнута по умолчанию.
- Ошибка инструмента — отдельная карточка, но прогон при этом продолжается.
- Reasoning показывается в свёрнутом блоке и дописывается по дельтам, без перерисовки всего блока.
- После завершения прогона видна его стоимость в формате `$0.000058` и токены.
- При остановке пользователем ложная ошибка инструмента не показывается.
- События браузерного потока инструментов различаются по типу (`tool.started`, `tool.called`, `tool.result`, `tool.failed`), а расход — `usage.step` и `usage.session`.
