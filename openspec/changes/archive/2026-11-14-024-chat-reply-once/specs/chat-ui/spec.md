# Spec Delta

## Purpose

Лента чата может содержать несколько ответов подряд. Каждый ответ относится к своему прогону и не переиспользует блок предыдущего ответа.

## ADDED Requirements

### Requirement: Ответ относится к своему прогону

Система SHALL выводить события прогона в блок ответа этого прогона: новый ответ не дописывает текст в предыдущие ответы ленты.

#### Scenario: Второе сообщение подряд

- **WHEN** пользователь отправляет второе сообщение после завершения первого ответа
- **THEN** текст второго ответа появляется в новом блоке, а предыдущий ответ остаётся неизменным

#### Scenario: События после второго сообщения

- **WHEN** во втором прогоне приходят текст, reasoning, инструменты, разрешения и usage
- **THEN** они отображаются в блоке второго ответа, а не в первом блоке ленты

#### Scenario: Перезагрузка во время прогона

- **WHEN** пользователь перезагружает страницу, пока прогон активен
- **THEN** страница показывает один блок ответа и продолжает выводить события в него
