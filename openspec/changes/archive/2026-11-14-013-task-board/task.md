## Goal

Заменить статусы в front-matter файлов задач одной таблицей `docs/tasks/BOARD.md` (номер, задача, статус) с жизненным циклом `создано` → `в работе` → `выполнено` → `закрыто`, чтобы взятая задача была видна другому агенту и человеку сразу после коммита в `main`, без чтения всех файлов.

## Non-goals

Трекер, БД, MCP-инструменты, блокировки через refs, автоматическое закрытие, изменение кода приложения, правка `.ai/wiki/`.

## Контекст

- Сейчас статус живёт в `status:` каждый задачи; чтобы узнать, кто взял, нужно читать все файлы или журнал коммитов.
- `docs/tasks/011` (OpenSpec) закрыта; change 003 — пилот, статус не меняется.
- Параллельно в worktree идёт 012 (OpenAPI) — её файл и строку в доске не трогаем, кроме удаления `status:`.

## Acceptance criteria

- [ ] `docs/tasks/BOARD.md` — таблица «№ | Задача | Статус», статусы только `создано`, `в работе`, `выполнено`, `закрыто`.
- [ ] Все незакрытые задачи из `docs/tasks/*.md` есть в таблице; 011 — `закрыто`, 003 и 012 — `в работе`, остальные — `создано`.
- [ ] `status:` убран из front-matter файлов задач и backlog: доска — единственный источник.
- [ ] `docs/tasks/README.md` и `AGENTS.md` описывают те же переходы и то же имя статусов, противоречий нет.
- [ ] `openspec/changes/003-runtime-chat-api` и `AGENTS.md`-раздел OpenSpec не противоречат новой схеме (файл задачи больше не держит статус).
- [ ] Backlog на доску не попадает; правило «агент не берёт» сохранено.
- [ ] `./gradlew test` зелёный без фильтра.
