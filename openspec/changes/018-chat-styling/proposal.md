# Proposal

## Why

Страница `/chat` реализована (004) и работает, но у неё нет ни одного стиля: в `src/main/resources/static/` есть только `js/`, внешний вид — браузерные дефолты. Приёмка 004 про разметку и стриминг, оформление туда не входило. Без оформления пользователь не отличает вопрос от ответа, не видит, что прогон идёт, а страница выглядит недоделанной.

## What Changes

- Один локальный CSS-файл `/css/chat.css`, подключённый со страницы; приложение остаётся офлайн.
- Лента диалога: пузыри пользователя и ассистента, ограниченная ширина, переносы, длинные строки не ломают вёрстку.
- Индикатор генерации виден только во время прогона, без правок `chat.js`.
- Композер закреплён внизу; кнопки, фокус и `disabled` оформлены.
- Баннеры «Нет связи» и «OpenCode недоступен» видны над лентой.
- Тёмная тема по `prefers-color-scheme: dark`; адаптив от 375px.
- Пустая подсказка скрывается, когда в ленте есть сообщение.

## Capabilities

### New Capabilities

- `chat-appearance`: оформление страницы чата — локальные стили, различимость сторон диалога, читаемость потокового ответа, состояния страницы, тёмная тема.
