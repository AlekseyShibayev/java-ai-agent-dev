# Spec Delta

## ADDED Requirements

### Requirement: Ответ на неизвестный запрос разрешения

Система SHALL отличать неизвестный или устаревший запрос разрешения от недоступности OpenCode и сообщать клиенту, что запрос больше не существует.

#### Scenario: OpenCode не знает requestId

- **WHEN** OpenCode отвечает 404 на `POST /api/session/{id}/permission/{requestId}/reply`
- **THEN** система отвечает клиенту 404 с сообщением о неизвестном запросе разрешения, а не 502

#### Scenario: OpenCode недоступен

- **WHEN** ответ на запрос разрешения не удаётся отправить из-за недоступности OpenCode
- **THEN** система отвечает клиенту 502
